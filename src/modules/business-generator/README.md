# Módulo 3 — Gerador de Negócios

**Responsabilidade (Doc. 08):** recebe o planejamento produzido pela IA e o transforma em estrutura do negócio.

Cria: estrutura do negócio, páginas, categorias, produtos, organização, fluxo, SEO, hierarquia.

- `planner/` — planejamento da estrutura (Doc. 04, Etapa 05)
- `structure/` — estrutura do negócio (páginas, seções, navegação)
- `seo/` — SEO inteligente (título, meta descrição, palavras-chave, hierarquia)
