# Módulo 5 — Editor

**Responsabilidade (Doc. 08):** permite ao usuário modificar qualquer parte do projeto.

Exemplos: trocar textos, alterar imagens, modificar cores, editar botões, adicionar seções, excluir elementos, mover componentes.

Todo ajuste manual acontece aqui.

- `actions/` — ações de edição (atualizar textos, cores, seções, páginas)
