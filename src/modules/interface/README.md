# Módulo 1 — Interface do Usuário

**Responsabilidade (Doc. 08):** toda interação com o usuário.

Inclui: tela inicial, chat, visualização do projeto, editor, configurações, feedback, tema claro/escuro.

**Não contém inteligência.** Apenas apresenta informações.

- `components/` — componentes de UI (chat, barra de progresso, painel lateral, pré-visualização)
- `hooks/` — hooks de interface (tema, estado do chat, etc.)
